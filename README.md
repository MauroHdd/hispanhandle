# Hispanhandle.com

New bilingual (Español / English) website for Hispanhandle: recruiting insurance agents in North Florida.

- `index.html` — the whole site (one page, no build step). The ES/EN button switches all text and remembers the visitor's choice.
- `assets/hispanhandle-logo.png` — logo.

## Publish
GitHub Pages: Settings → Pages → Source: "Deploy from a branch" → `main` / root. Then point hispanhandle.com's DNS to GitHub Pages and add the domain under Pages → Custom domain.
